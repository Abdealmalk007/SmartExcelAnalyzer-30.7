# SmartExcelAnalyzer 30.7.2

**PRO TECH Smart Excel Analyzer** — Windows 10/11 x64 desktop application for Excel data analysis and reporting.

## الإصدار 30.7.2

حزمة تثبيت موحّدة تضم:
- مثبت الإصدار الأساسي 30.7.0
- تحديث 30.7.1 التراكمي
- تحديث 30.7.2 الذي يلغي شاشة تسجيل الدخول المحلية

يعمل المثبت بالترتيب المذكور؛ يحافظ التحديث وفق وثائقه على ملفات Excel والتقارير والإعدادات وقواعد البيانات. مع ذلك، يوصى بنسخ البيانات المهمة احتياطيًا قبل التثبيت أو الترقية.

### التنزيل

من [GitHub Releases](https://github.com/Abdealmalk007/SmartExcelAnalyzer-30.7/releases/tag/v30.7.2) نزّل `SmartExcelAnalyzer_30.7.2_Setup.exe`، ثم شغّله بصلاحيات المسؤول.

- متطلبات النظام: Windows 10/11 x64.
- لا يحتاج المستخدم إلى تثبيت Python.
- الحزمة غير موقّعة بشهادة Authenticode ما لم يعلن خلاف ذلك.
- يجب عدم تجاوز تحذيرات الحماية دون التحقق من مصدر الملف وبصمته.
- أيقونة جديدة مخصصة لتحليل البيانات والرسوم البيانية.
- هذا المستودع مخصص للوثائق والأيقونة والحزم التنفيذية، وليس للنشر المفتوح للشيفرة المصدرية.
